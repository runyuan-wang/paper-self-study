# 论文防幻觉自学 / Paper Self-Study

一个给AI与人类共用的单篇论文学习方法：有证据地读懂，而非把摘要扩写。以小入口和按需模块组织，不默认多agent、指定模型或复杂平台。

## 怎么用
把整个目录放进所在系统的技能扫描根，验证并按该系统规则加载目录。LingTai可放 `.library/custom/paper-self-study/`，运行 Skills 手册所给结构validator；文件落盘不代表目录已加载，下一次自然reload/molt或必要的一次定向catalog rebuild才更新索引。接收者自己管理安装，无自动改配置脚本。

对agent说：“用论文防幻觉自学读这篇论文，先大白话讲关键机制，再给我一道自测题。”提供PDF、合法公开链接、论文标识或正文片段即可。只有摘要也可导读，但会明确边界。

入口 `SKILL.md` 决定当前要读哪个分支：
- `reference/plain-language/`：大白话短讲，一次一个问题，术语就地翻译，深读按需展开，中断可接回。
- `reference/evidence/`：来源、覆盖、主张与唯一标签规则。
- `reference/mechanism/`：符号、同一输入贯穿例子与对照。
- `reference/appraisal/`：按类型质疑研究和适用性。
- `reference/self-study/`：练习、延后答案、按实际反馈补学。
- `reference/delivery/`：可核可迁移的笔记与验收。
- `assets/learning-card.md`：可选记录模板，不是必须填完的表。

不触发：代写完整学术论文、系统综述、医学个体诊疗、不具备证据却承诺零幻觉。没有工具时说明缺什么，不伪装检索、OCR或复现。

## 状态与许可
v1.1.0，新增注意力友好的大白话模块；这是呈现偏好支持，不是诊断或治疗功能。结构检查与构造样例验算不代表真实论文学习效果验证；首次使用后请反馈哪一步仍不懂。
