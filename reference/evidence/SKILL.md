# 证据：先知道自己实际读到了什么

## 何时读 / 输入 / 产出
何时：开始、材料变化、发现似真引文或强结论无出处。
输入：论文文件/链接/标识、用户问题、已有材料。
产出：来源卡、实际阅读覆盖、决定性主张的定位与标签、未核问题。需要表格时按本模块的来源/覆盖/主张字段记录，普通小问题可用几句话，不制造仪式；可选模板由主入口统一导航。

## 单一归属的证据语义
以下四种是陈述来源，不是证据强弱排行榜；其他模块引用这里，不另造分类。
- F：原文明确报告/陈述。写“作者报告……”；原文事实不保证世界事实，结论可靠度另由研究设计判断。
- D：读者可核的推导/重新计算。写明原文前提、步骤、单位、公式与核验方法；不是作者实际运行记录。
- E：自造教学示例或类比。数据/输入/情节明确标“构造”；说明与真实研究不一致的简化，不能证明方法普遍优越。
- H：猜想、外推、可能机制或作者意图推断。给根据/替代解释/未确定部分；无法合理支持时不猜。
一个段落有不同类型时拆开标，不能以末尾统一标签把推断洗成事实。

## 执行
1. **核身份**：核题名、作者、年份、期刊/会议/预印本、DOI/arXiv/PMID。优先出版方/arXiv/PubMed等原始登记页；Crossref/OpenAlex可核元数据，不证明读过全文。检索/全文工具按运行环境实际提供的手册使用；没有工具则标“外部身份未核”，仍可解释用户给的片段，不伪称已确认发表。
2. **定版本**：原文版本/日期，相关代码的 commit/config、勘误/撤稿/关注声明（能查询时查权威记录；未查记未查）。未来日期/标题相近/DOI解析到别文时暂停该身份结论，不能猜成错误或正常。
3. **定覆盖**：区分 metadata-only、abstract-only、excerpt、main-text、full-text-with-supplements；列正文/图表/附录/补充材料实际可访问与实际已读两套状态。能下载≠已读；提取文本≠已看图；OCR可疑数字回看原页，否则记不确定。
4. **定位少量关键主张**：每条记原话/释义、F/D/E/H、文献版本、页/节/图表/公式或短原文定位、证据支持与不支持的范围。二手引用只可写“本文转述某研究”，未读被引研究不能冒充一手。
5. **身份与效度分离**：出版状态可为正式发表或预印本；访问范围按上步；偏倚/对照/适用性按质疑模块。已核预印本既不是假文献，也不是同行评议定论。

## 缺材料与冲突分支
- 只有摘要：提供“摘要级导读＋待核关键问题”，不补摘要未给出的方法、效应大小、公式证明或全文限制。不阻断所有帮助，也不叫完整精读。
- 主文有、附录无：先解释已见机制，对依赖缺失附录的主张留空；请求缺失材料或合法开放来源，不绕付费墙。
- 文本与图/表/代码矛盾：保留两个原件与版本、定位、影响，标“未解决”。不一律信代码或偷偷调数字。
- 只有宣传/截图/LLM引用：先当线索或该截图局部，不补作者、期刊、数据；无法核时明确“不能从这份材料确认”。

## 验收与常见坑
任一硬结论都能回到具体版本和位置；未核身份不能写“已发表”，未读全文不能写“通读”。若为方便解释增加了E/H，必须就在相关内容处标明。
DOI真实但标题不符→身份错配，不能沿用；主张有引文却不支持→引用错配，弱化/去掉该主张；查不到撤稿→只能说本次未发现或未查，不能保证不存在。
