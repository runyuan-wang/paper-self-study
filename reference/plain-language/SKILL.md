# 大白话：一口能吃下，深处仍走得到

## 何时读 / 输入 / 产出
何时：用户说“大白话/听不懂/别堆术语/一次讲一点/讲到哪了”；未知基础时默认先用本模式，熟悉读者可按其偏好跳过。
输入：用户当前问题、已核原文、已讲到的位置和读者反馈。证据语义引用 [证据模块](../evidence/SKILL.md)；不能用简化洗掉不确定性。
产出：一个短讲块、可选展开入口和一句可恢复的位置提示。只调整呈现，不推断疾病、能力、情绪或诊断；不同读者偏好不同，不声称这种模式治疗注意力问题。

## 默认短讲块
一次只解决一个问题，约3—6句短句，可按用户反馈增减；这是起步长度，不是删科学边界的硬配额。
1. **先说人话结论**：这篇/这一步到底做什么，用主动语态和具体对象。
2. **一个贯穿例子**：用可看见的输入→动作→结果，数值或情节构造就当场标“教学例子，不是论文数据”。
3. **说为什么与证据边界**：关键改变在哪里；原文支持什么、还没证明什么；必要原文位置短标，不淹没正文。
4. **停在一个门口**：可选“继续例子/看公式/看证据/换个说法/先停”。不要每句话都提问，也不强迫用户选择或答题才能继续。

## 分层而不是删减
- 第一层：现实问题＋一句结论＋一个例子＋边界。第二层：完整关键步骤。第三层：公式/推导/研究设计/反证，按需打开。
- 术语首次出现就翻译，例如“消融：拿掉一个部件，看结果怎么变”；之后固定同一称呼。不把比喻当精确机制，不把“明显/其实很简单”当解释。
- 一段一个动作；优先短句、明确指代，列步骤只在真有顺序时用。不要同时堆多个类比、不断换例子、用英文缩写替代解释。
- 图只回答一个问题；字与图追踪同一对象。证据引用和完整审查可折叠，但结论的关键限制不能藏到无人会读的角落。
- 不把专业内容讲幼稚，不用“你基础差/你肯定记不住”；不硬造情绪、健康史，不靠夸奖代替纠错。

## 中断、卡点与练习
中断后给一句定位：“我们正在比较X；刚讲到Y；下一步看Z”，只恢复当前问题，不重发全篇。没有此前记录则诚实说不知道停哪了，问最小必要问题。
用户说不懂时换一种表达或再缩一个算例，不原样重复长文；问一个具体卡点也可，不用整套能力问卷。
自测可选，用户要“直接讲”就直接讲。要练习时按 [自学模块](../self-study/SKILL.md) 先一题、答案延后。没回答不催、不记录已掌握，不把停下来当失败。

## 构造示范（不是论文结论）
问题：“按权重汇总是什么意思？”
短讲：“它就是让某些数在结果里占更多份量。用教学数2和8：各占一半，结果是5；让8占四分之三，结果是6.5。区别从分配份量那一步开始。6.5更大不代表更准——还没告诉我们正确答案是什么。”
可选展开：想看乘法步骤，再读 [机制模块](../mechanism/SKILL.md) 的同一例子。说明只示范表达与算术，不验证真实阅读效果或方法性能。

## 验收
读者不用先懂术语也能说出当前在解决什么；短讲保留证据类型与关键限制；展开入口真能到对应细节；位置提示只说实际已有进度。第一次真实使用时收集一个具体卡点，据实调整分块，不承诺人人适用或零幻觉。
